# 計量テキスト分析ツール v1.0

テキストデータを簡単に計量テキスト分析できる Streamlit アプリケーションです。

---

## 動作環境

- **OS**: Windows 10 / 11
- **Python**: 3.13（推奨：Microsoft Store 版）
- **推奨メモリ**: 8GB 以上

---

## 導入手順

### ステップ1：Python のインストール

1. [Python 公式サイト](https://www.python.org/downloads/) または Microsoft Store から Python 3.13 をインストール
2. インストール時に「Add Python to PATH」にチェック（または Microsoft Store 版を選択）

### ステップ2：アプリの取得

**GitHub からクローン**
```bash
git clone https://github.com/takechan-hundred-say/text-mining-app.git
cd text-mining-app
```

または [Releases](https://github.com/takechan-hundred-say/text-mining-app/releases) から最新版をダウンロードして展開。

### ステップ3：セットアップ

`setup.bat` をダブルクリックするか、以下のコマンドを実行：

```bash
python -m pip install -r requirements.txt
python -m streamlit run main.py
```

自動的にブラウザが開き、アプリが起動します。

---

## インストーラー版（Python 不要）

リリースページにある `text-mining-app-installer.exe` を利用すると、Python がインストールされていない PC でもアプリを利用できます。

1. インストーラーを実行し、画面の指示に従ってインストール
2. スタートメニューから「計量テキスト分析ツール」を起動

> **注意**: R を使用する場合、別途 R のインストールが必要です。

---

## 外部ツールのセットアップ（必要な場合）

### MeCab + UniDic（高精度形態素解析）

標準の Janome より高精度な解析が可能です。

1. [MeCab 公式サイト](https://taku910.github.io/mecab/#download) から Windows 版インストーラーをダウンロード
2. インストール後、アプリ起動時に「MeCab + UniDic（高精度）」を選択
3. （オプション）UniDic を導入するとさらに高精度に

### R（グラフ描画・コレスポンデンス分析）

R を用いたグラフ描画やコレスポンデンス分析に対応しています。

1. [R 公式サイト](https://cran.r-project.org/) から R をインストール
2. アプリ起動時にサイドバーの環境確認で「[OK] R: ...」と表示されれば連携完了
3. 複数バージョンがインストールされている場合、新しい方が自動選択されます

### LM Studio（ローカル AI 分析）

LM Studio を使うと、ローカル環境で AI によるテキスト要約・分析が可能です。

1. [LM Studio](https://lmstudio.ai/) をダウンロード・インストール
2. 任意のモデルをダウンロード（例：llama-3.2-3b-instruct）
3. 左側の Chat タブでモデルを選択
4. 起動後、Local Server（ポート1234）を開始

## 基本的な操作方法

### 1. ファイルの読み込み

| ファイル形式 | 説明 |
|---|---|
| `.txt` | プレーンテキスト |
| `.csv` / `.xlsx` | 表データ（属性情報あり） |
| `.docx` | Word 文書 |
| `.pdf` | PDF 文書 |

表データ（CSV/XLSX）を読み込むと、テキスト列と属性列（年代・性別など）を選択できます。

### 2. 分析の流れ

1. **ファイルの読み込み**: メイン画面からアップロード
2. **品詞の選択**: サイドバーで対象品詞（名詞・動詞・形容詞・副詞）を選択
3. **複合語の定義**: 必要に応じて1語として扱いたい語句を設定
4. **除外設定（ストップワード）**: 分析から除外する単語を指定
5. **分析実行**: 自動的に集計とグラフが生成

### 3. プロジェクトの保存と復元

分析中のデータは `.pkl` ファイルとして保存・復元可能です。
- サイドバー下部の「現在のプロジェクトを保存」から保存
- 「プロジェクトの復元（読み込み）」から過去のデータを読み込み

## 分析機能一覧

### 基本項目

| 機能 | 説明 |
|---|---|
| **記述統計** | 文字数、文章数、単語の異なり数などの基本統計 |
| **データ表** | 抽出された単語の一覧表示（ソート・フィルタ対応） |
| **出現頻度** | 頻出語句のグラフ（R 版グラフにも対応） |
| **クロス集計** | 属性データ × 単語のクロス集計とコレスポンデンス分析 |

### 応用項目

| 機能 | 説明 |
|---|---|
| **N-gram** | 連続する2単語（バイグラム）の出現頻度を可視化 |
| **ワードクラウド** | 出現頻度に応じた単語の大小表示 |
| **共起ネットワーク** | 一緒に使われやすい単語同士を線で結んだネットワーク図 |
| **TF-IDF** | 文書内での単語の重要度をスコア化 |
| **感情分析** | ポジティブ/ネガティブ/ニュートラルの判定（東北大極性辞書） |
| **KWIC** | 単語の前後文脈を一覧表示 |
| **クラスター分析** | 単語の共起関係に基づく階層的クラスタリング |
| **プロセスフロー** | テキストを段階分割し、語句の出現推移を分析 |

### AI 分析

| 機能 | 説明 |
|---|---|
| **テキスト要約・分析** | LM Studio 経由でローカル LLM による要約を実行 |
|   - API 直接実行 | テキストを直接 API に送信 |
|   - ファイル経由 | テキストファイルを LM Studio GUI に読み込ませる（文字数制限なし） |
| **AI アフターコーディング** | 頻出単語から同義語辞書を自動作成 |

## トラブルシューティング

### 「R が見つかりません」
- R がインストールされていない場合は [CRAN](https://cran.r-project.org/) からインストール
- インストール済みでも表示される場合は、インストーラー版の再実行、または PATH を確認

### 「MeCab が見つかりません」
- [MeCab 公式サイト](https://taku910.github.io/mecab/#download) からインストール
- インストール後はアプリを再起動

### アプリが起動しない
- `python --version` で Python 3.13 が入っているか確認
- `pip install -r requirements.txt --upgrade` でパッケージを更新
- エラーメッセージをコピーして [Issues](https://github.com/takechan-hundred-say/text-mining-app/issues) に報告

### LM Studio の API エラー
- LM Studio で Local Server（ポート1234）が起動しているか確認
- 別のアプリがポート1234を使用していないか確認
- モデルが正しく読み込まれているか確認
